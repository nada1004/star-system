# 안 쓰는 파일 (2026-08-21 정리)

`index.html`, `build.mjs` 번들 목록, 어떤 JS의 동적 로더에서도 참조되지 않는 것을 확인하고
이 폴더로 옮겼습니다. `_deprecated/`(2026-07-18에 먼저 정리된 구버전 원본 모듈들)와는
발견 경위가 달라서 폴더를 분리했습니다.

- **stats-univmatrix-renderer.js** — 대학 간 상대전적 매트릭스 렌더러. 기능 자체는 완성돼
  있지만 어디에서도 호출되지 않는 고아 파일입니다. 다시 쓰려면 `index.html`이나 관련 lazy
  loader에 스크립트 태그/동적 로드를 추가하고 호출부(예: 통계탭)에 진입점을 연결해야 합니다.

- **chunk-board.js.stray-copy** — `dist/js/chunk-board.js`(빌드 산출물)가 실수로 소스 폴더
  `js/`에도 남아있던 복사본입니다. 실제로 서빙되는 건 `dist/` 쪽이고, 이 파일은 그냥 남은
  잔재입니다. 다시 필요할 일은 없고, 혹시 최신 빌드가 깨졌을 때 비교용으로만 참고 가치가
  있습니다.

- **sw.js.stray-copy** — 루트 `sw.js`(실제 서비스워커, `index.html`에서
  `/sw.js`로 등록됨)의 오래된 복사본이 `js/` 폴더에도 있던 것입니다. `CACHE_VERSION`이
  실제 파일보다 뒤처져 있어서 착각하고 잘못 배포하면 캐시 문제가 생길 수 있으니, 다시
  쓰려면 반드시 루트 `sw.js`와 내용부터 맞춰야 합니다.

- **ui-premium-v2.css.duplicate-of-deprecated** — `_deprecated/ui-premium-v2.css`로
  이미 안 쓰는 파일로 판정났던 것과 같은 이름의 파일이 `css/` 폴더에 또 있었습니다.
  `_deprecated/` 쪽이 원본이고 이건 그 이후에 실수로 다시 생긴 복제본으로 보입니다.

**삭제하지 않고 폴더만 분리**했습니다. 필요 없다고 확신하시면 지우셔도 되고, 혹시 실제로
필요했던 것으로 밝혀지면 원래 위치(`js/`, `css/`)로 옮기시면 됩니다.
